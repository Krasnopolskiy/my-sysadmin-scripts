== 2. stopping the loop with a signal after 7s ==

$ timeout -s INT 7 ./script.sh
monitoring every 5s -> /home/ubuntu/my-sysadmin-scripts/monitor.log (Ctrl+C to stop)

$ tail -3 monitor.log
 16:38:03 up  3:43,  1 user,  load average: 0.00, 0.00, 0.00

--- monitor stopped 2026-09-10 16:38:05 ---

== 3. error handling ==

$ ./script.sh abc
error: snapshot count must be a non-negative integer, got 'abc'
usage: ./script.sh [snapshots]
exit: 2

$ MONITOR_LOG=/root/forbidden.log ./script.sh 1
error: cannot write to /root/forbidden.log
exit: 3

$ MONITOR_LOG=/tmp/nested/dir/monitor.log ./script.sh 1   # directory created on demand
monitoring 1 snapshot(s) every 5s -> /tmp/nested/dir/monitor.log
done: 1 snapshot(s) -> /tmp/nested/dir/monitor.log
exit: 0
